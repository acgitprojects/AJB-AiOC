# Cloudflare Deployment Guide

## Problem: Service Binding Error on First Deploy

When deploying to Cloudflare Workers for the first time, you may encounter an error:

```
Service binding 'WORKER_SELF_REFERENCE' references Worker 'ajb-ops-centre' which was not found.
```

This happens because the OpenNext migration tool automatically creates a `wrangler.jsonc` file that includes a self-reference service binding. This binding is only needed for advanced edge caching features and requires the worker to already exist in your Cloudflare account.

## Solution

A post-build script has been added that automatically removes the service binding from generated configs during the first deployment. This script runs before the `wrangler deploy` command.

### Deployment Process

#### First-Time Deploy (Production)
```bash
npm run deploy:cf
```

This command:
1. Builds the OpenNext application
2. Removes problematic service bindings from generated config
3. Deploys to Cloudflare Workers

#### Staging Deploy
```bash
npm run deploy:cf:staging
```

#### Preview Locally
```bash
npm run preview:cf
```

## Enabling Edge Caching (Post-Deployment)

After your first successful deployment, you can enable edge caching optimization through service bindings:

### Step 1: Create R2 Bucket
```bash
npx wrangler r2 bucket create aioc-opennext-cache
```

### Step 2: Uncomment Configuration
In `wrangler.toml`, uncomment the `[[services]]` section:

```toml
[[services]]
binding = "WORKER_SELF_REFERENCE"
service = "ajb-ops-centre"
```

Also uncomment the `[[r2_buckets]]` section:

```toml
[[r2_buckets]]
binding     = "NEXT_INC_CACHE_R2_BUCKET"
bucket_name = "aioc-opennext-cache"
```

### Step 3: Re-deploy
```bash
npm run deploy:cf
```

## Configuration Files

- **wrangler.toml**: Main Cloudflare Workers configuration (checked into git)
- **wrangler.jsonc**: Auto-generated by OpenNext migration during build (not in git)
- **open-next.config.ts**: OpenNext adapter configuration
- **scripts/fix-wrangler-config.js**: Post-build script that removes service bindings

## Troubleshooting

### Build succeeds but deploy fails
- Check that you're using `npm run deploy:cf` (includes the fix script)
- Verify `wrangler login` has authenticated you with Cloudflare
- Check Cloudflare account has active workers enabled

### Script doesn't exist error
- Ensure `scripts/fix-wrangler-config.js` file is present
- Run `npm install` to reinstall packages

### Service binding errors persist after migration
- Delete `.open-next/` directory: `rm -rf .open-next/`
- Try deployment again: `npm run deploy:cf`
